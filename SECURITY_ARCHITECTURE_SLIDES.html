Phân Hệ Quản Lý Khóa Mật Mã (KMS & Secret Shield)

Mã hóa AES-256-GCM toàn bộ dữ liệu tĩnh, cô lập Master Key sâu trong mạng ngân hàng và giải mã JIT trong RAM.

lock Thuật Toán AES-256-GCM

• Khóa 256-bit: Phái sinh từ Master Key qua băm SHA-256.

• 12-Byte IV Ngẫu Nhiên: Sinh mới cho từng token, chống phân tích mẫu bản mã.

• 16-Byte GCM Tag: Xác thực toàn vẹn, chống can thiệp bản mã (Tamper-Proof).

%{[Base64(IV + Cipher + Tag)]}%
filter_center_focus KmsEncryptionFilterService

• Quét Đệ Quy: Duyệt tự động qua String, Map, List, JSON Tree (Jackson).

• Batch Processing: Gom mảng token nhạy cảm gửi mã hóa theo lô.

• High Availability Fallback: Tự động dùng AES-256 cục bộ nếu KMS bận.

%{enc:raw}% ➔ %{cipher}%
memory Giải Mã JIT Trong RAM

• Không Giải Mã Sớm: Dữ liệu trên Redis/Cloud luôn là bản mã.

• RAM Tạm Thời: Plaintext chỉ tồn tại trong mili-giây tại tiến trình Worker.

• Zero Disk Footprint: Không bao giờ ghi Plaintext xuống ổ đĩa hay file swap.

Port 8766 (Bank Internal KMS)
